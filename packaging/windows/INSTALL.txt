AVAC Desktop 0.1.7 preview 1 - Windows offline installer

LANGUAGE AND NUMBERS
Setup offers English (default), French, Spanish, Italian and German.
The selected language is used for licensing information and the scientific-use
notice, followed by the full official English AGPL. The translated information
is a summary, not a replacement license. No extra license restrictions apply.
On a first installation, Setup's choice initializes the app language; upgrades
preserve existing app preferences. In Edit > Settings, select Language and Save,
then restart the app. Decimal separator (point or comma) is independent, changes
immediately after Save, and is remembered. Scientific files retain their formats.

REQUIREMENTS
Windows 11 x64, Intel or AMD processor. Windows 10, ARM and 32-bit Windows
are not supported by this first installer. Standard Windows multimedia
components are required for video export; Windows N needs Microsoft's Media
Feature Pack through Windows Optional Features. Setup checks for that component.
4 GB RAM minimum for small examples; 8 GB or more recommended. Large terrain
models can need substantially more memory. Allow at least 4 GB free space for
the installer, application, bundled source and first-run solver extraction,
plus separate space for project inputs and simulation output.

No Python, QGIS, GDAL, compiler, Visual Studio, Microsoft MPI, separate Qt
installation, paid license or administrator account is required. The required
Python interpreter, GDAL/PROJ, OpenBLAS, Qt, C/C++/Fortran runtime libraries and
both AVAC/WAVE solvers are included. The numerical libraries use OpenBLAS,
not an external Intel MKL/MPI installation. Core operation is offline.
Internet access is only needed for optional online background maps.

INSTALL
Copy AVACDesktop-0.1.7-preview.1-Setup-x64.exe to the other computer and run it.
Review the scientific-use notice and license, keep the default options and
installation folder, then choose Install. Start AVAC Desktop from the Start
menu or desktop shortcut. Install for each Windows user who needs the software.
The default folder is %LOCALAPPDATA%\Programs\AVAC Desktop.

This preview installer is unsigned. Windows may identify its publisher as
unknown. Obtain it from the project owner and verify its SHA-256 against the
supplied checksum before deciding to proceed. No security setting needs to be
disabled. Public signing/Store delivery remains a separate release step.

TUTORIAL
Choose Help > Load tutorial to open the included terrain and snow release
polygons. No download is required. Save the project in your own writable folder
before preparing and running; its inputs and results are stored there.

START A CASE
Save each project in a dedicated writable folder in Documents or another data
location, rather than in the application folder. Save brings required inputs
under that folder; completed runs register automatically. Move the whole case
folder to transfer it and open its .avacproj. Solvers extract their bundled
runtime into %APPDATA%\AVAC Desktop\runtime\desktop on first use; no download is made.
First preparation can take longer while extraction and integrity checks finish.
DEMs without a CRS are supported as local XY grids with metres assumed. The
Console warns and online map/satellite backgrounds are disabled. Release,
lake, profile and gauge inputs must already share the DEM's XY coordinates.

UPDATE AND UNINSTALL
Close AVAC Desktop before installing another build or uninstalling it. Run
Setup again to replace an existing installation. Saved projects and preferences
are retained. Use Windows Settings > Apps > Installed apps > AVAC Desktop >
Uninstall. The uninstaller removes only its recorded program files and empty
directories; it preserves other files, saved projects, user preferences and
the reusable solver cache. Do not manually delete a project folder to uninstall.

FIRST INSTALLATION CHECK
The installer and its installed native workflow are tested on the development
computer with a minimal Windows PATH and isolated app-data directories. This
does not establish acceptance on a freshly installed Windows VM. On the target
PC, launch the program, create/save a small case, run AVAC and optional WAVE,
close/reopen the project and inspect the results. Test update/uninstallation
while confirming that your project folder remains intact.
